## 测试环境

- 前端：Vue 3 + TypeScript + Vite 8.3.0（Element Plus / ECharts / Pinia / Axios），`http://localhost:5174`
- 后端：Spring Boot 3.3.5 + SQLite，`http://127.0.0.1:8001`，使用独立数据库副本
- 工具：Temurin JDK 21.0.12、Maven 3.9.16、Node.js 24.21.0、npm 11.19.0
- 浏览器：Microsoft Edge 155（Playwright 驱动），默认视口 1440×900，整页截图
- 测试数据：首次启动自动初始化的 6 个账号、5 条水价规则、60 台水表、6 条示例异常与 420 条上报数据

## 结论摘要

- 功能：25 个用例全部通过，未发现功能缺陷。
- 非功能：性能、安全、兼容性、可靠性、易用性、无障碍共 21 个用例，20 项符合预期。
- 缺陷与风险：
  - D01（低）：分页参数类型错误时返回 HTTP 500，应为 400；前端不会产生该请求，属接口健壮性问题。
  - O01：后端不可用时页面直接显示英文技术提示。
  - O02（中）：跨域允许任意来源且允许携带凭据，公开部署前须收敛为白名单。
  - O03（低）：单个页面 chunk 超过 500 kB 的构建告警。
