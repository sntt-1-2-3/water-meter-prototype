## 1. 说明

本矩阵建立“需求/验收项 → 测试用例 → 执行方式 → 执行结果 → 证据”的追踪关系，用于回答三个问题：需求有没有对应用例、用例有没有实际执行、执行结果有没有证据。

### 1.1 状态图例

| 标记 | 含义 |
|---|---|
| ✅ 通过 | 有直接执行证据（界面操作或接口调用），结果符合预期 |
| ◐ 部分覆盖 | 由后端自动化测试覆盖、只覆盖部分子场景、或需求本身存在能力边界 |
| ○ 未执行 | 已设计用例但本轮未实际执行，不能视为通过 |
| ✗ 不符合 | 已执行且结果不符合预期，或需求对应能力未实现 |

### 1.2 证据缩写

| 缩写 | 说明 |
|---|---|
| FR | 功能测试报告（`test/智水云-AI水表收费管理系统功能测试报告-20261013.docx`） |

> 说明：标注为 ◐ 的条目不能计入“已通过”，只能说明已有实现或部分证据；标注为 ○ 的条目在补齐执行前不得在验收结论中写“通过”。
