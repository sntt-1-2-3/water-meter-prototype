# 水表照片测试样例与授权

这些是公开授权的真实水表照片，仅作为功能验证样例，不是本系统训练数据，也不能据两张图片推断各种水表的识别准确率。不要把样例读数保存到不对应的真实用户水表中。请在独立测试数据库内演示。

## 清晰的机械滚轮水表

- 文件：`water-meter-aka.jpg`，原图未修改。
- 原作：[Water meter (aka).jpg](https://commons.wikimedia.org/wiki/File:Water_meter_(aka).jpg)。
- 作者：André Karwath（Aka）。
- 授权：[CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/)。复用或修改图片时，保留作者署名、来源与授权链接；修改后的图片按该授权要求共享。
- 人工观察：主滚轮黑字为 `00070`，红字为 `812`；按该表盘红字三位小数理解为 `70.812 m³`。右侧下方的小指针盘不包含在这个三位小数读数内。
- 数字窗口约为原图的 `x=510, y=640, width=390, height=75`，只用于帮助测试框选，程序没有针对这张图片写死坐标或答案。
- 新版在定位到黑红数字窗口后，会逐位识别 `00070812` 并按检测到的三位红字建议 `70.812`，仍须人工核对。如果其他图片未能确定黑红分界，不能直接把整数 `70812` 当成立方米读数使用。

## 使用范围

照片 OCR 只提取可见字符；表号、单位、小数位、半转数字必须由操作人员核对。该版本不承诺读取指针式表盘，也不自动把加仑等其他单位换算成 m³。请勿向样例、截图或 GitHub 提交真实住户的姓名、地址、账号密码、JWT 或数据库文件。
