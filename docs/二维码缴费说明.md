# 二维码缴费（模拟版）

客户在“我的用水”或“个人账单”点击“扫码缴费”，先显示二维码，不再点击一下就记为已支付。扫码打开 `/pay/{账单编号}`，登录有权限的账号后查询服务器账单，再二次确认模拟支付；成功生成 SIM- 流水，桌面二维码窗口每5秒查询并更新为已结清。后台财务原有模拟收费操作保留。

## 重要边界

- **不是真实微信、支付宝收款码**，不发生扣款或银行清算。请勿进行真实转账。
- 二维码只是账单网页入口，不是锁价订单，不包含密码、JWT、住户资料或应付金额。链接没有付款授权作用；获取和支付账单都由后端按当前账号及绑定水表检查权限。
- 扫码、打开网页、刷新、取消或关闭窗口不产生支付记录；只有确认后才调用既有幂等支付接口。
- 金额由服务器计算。确认前重新查询最新水费、违约金及应缴；跨日期等情况下最终以服务端最新金额为准。
- 同账单重复支付仍只产生一笔模拟付款；账单已结清时不再显示待付款二维码。
- 真实收款后续需要独立接入支付商的商户下单、签名校验、支付通知验签及幂等回调；不能把“生成二维码”或前端按钮当作真实到账证明。

## 手机演示

`localhost`、`127.0.0.1` 是当前设备自己，手机扫码不能访问电脑的本机地址。当前页面会明确提示，可先点“在浏览器打开支付确认页”验证流程。

如果部署到了手机可访问的网站，在根目录 `.env.local` 配置其真实根地址，并重启前端：

```dotenv
VITE_PUBLIC_APP_URL=https://实际可访问的网站域名
```

该地址应部署同一版前端，并正确配置 `/api` 反向代理到对应后端；历史路由需回退到 index.html。不要填后端8000端口，不要附带密码、token、查询参数或子路径。生产环境使用 HTTPS。此配置**不会**自动改变防火墙、服务监听地址、开放公网或代替网站部署。本轮未配置外网访问，也未实测手机摄像头扫码。
